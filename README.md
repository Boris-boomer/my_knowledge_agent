# 📚 个人知识库问答 Agent

基于你的本地文档构建的智能问答系统。上传文档（PDF、Word、TXT），像和 ChatGPT 聊天一样提问，回答基于你自己的内容。

## ✨ 特性

- 🔍 **语义检索**：基于向量数据库 + BM25 混合检索，准确理解你的问题
- 🎯 **重排序精排**：检索结果二次精排，提升回答质量
- 💬 **流式对话**：逐字显示回答，体验流畅
- 📤 **多文件上传**：支持批量上传 `.txt` / `.pdf` / `.docx` 文件
- 🔘 **深度检索开关**：可选的 Vectorless RAG（文档树导航检索），更准但更慢，按需开启
- 🔒 **本地运行**：所有数据在本地，隐私安全
- 💰 **成本追踪**：自动记录每次调用的 Token 消耗
